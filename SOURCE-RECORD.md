# GitHub Pages export source record

This static export was generated from the independently reviewed Archivo 21 Compatibility Edition commit `4baa011175ae6f6ba2c892df38eb39fa7b567859`. It preserves 204 known HTML routes as ordinary static files for GitHub Pages.

GitHub Pages cannot supply the reviewed edge response headers. A matching CSP is therefore included as an HTML meta policy; `X-Content-Type-Options` is not controllable on this host.

The five-refresh Compiler trigger is active as a progressive JavaScript enhancement. It counts five reloads of the same page in one tab within 15 minutes, resets after navigation, and uses only browser session storage (no identifier, cookie, analytics, or server request). The destination is the recorded temporary route `https://archivo21.org/upupdowndownleftrightleftrightbaastart/`. The authoritative Compiler bundle remains a separate recovery task; this trigger does not substitute for that source recovery.
