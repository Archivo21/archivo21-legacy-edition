# GitHub Pages source record

The public Legacy Edition is maintained in
`Archivo21/archivo21-legacy-edition` and deployed by GitHub Pages to
`web.archivo21.org`.

The 2026-07-30 release imports the independently reviewed pre-visual
Compatibility Edition candidate `9c31d8c` into the public GitHub repository.
It combines that candidate with the two existing GitHub-only Scaffold support
records and preserves all 240 HTML routes as ordinary static files.

The release includes:

- the 256-file Tiny-Tile Galaxy bank and reviewed per-page assignments;
- the complete Compiler, including literal text-mode control panels;
- normal Compiler CRT/terminal scanline backgrounds;
- plain-blue BSOD and plain-black logo/POWER states;
- standard and floppy-friendly Scaffold packages with recorded differences;
- institution-first homepage and complete A-Z index;
- broad ANHQV-TS2 recruitment language for Simmers and ANHQV fans;
- click-only navigation from `/` to every HTML page.

GitHub Pages cannot supply the previously reviewed edge response headers. A
matching CSP remains included as an HTML meta policy;
`X-Content-Type-Options` is not controllable on this host.

The five-refresh Compiler trigger is a progressive JavaScript enhancement. It
uses tab-local session storage only, with no identifier, cookie, analytics or
external request. The production origin is GitHub Pages; no ChatGPT Site
deployment is authoritative.
