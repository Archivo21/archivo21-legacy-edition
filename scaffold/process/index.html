Creating the Archivo 21 Project Scaffold

Record type: revised and redacted development reconstruction
Release: 0.1.0-alpha.1
Date: 29 July 2026
Contributors: lcd97 (ANHQV-HUM-001) and Archivo 21 (ANHQV-AI-001)

Status of this record

This is a curated provenance record, not a verbatim transcript. Private personal material, unrelated correspondence, repetition, security details and person-directed material have been removed. Fuller source records remain preserved privately.

1. The problem appeared inside a real project

The Scaffold emerged while developing the ANHQV × The Sims 2 Preservation Project. The work needed to preserve not only outputs, but also the means by which those outputs were produced.

Preserve the output and the means by which the output was produced.

2. Project and institution separated

Archivo 21 became the institution developing preservation methods and records. ANHQV-TS2 remained an independent project with its own subject, identity and future.

Structure without annexation.

3. Institutional machinery became an open Scaffold

The question became whether people with serious knowledge, material or ideas could use a durable project structure without surrendering their own names, domains, governance or futures.

4. The reconstruction over-designed before it built

Twenty-three private discussion rounds established principles for openness, attribution, versions, archives, human-AI responsibility, consent and non-endorsement. The work became constitutionally detailed before a usable pack existed.

5. The pivotal interruption

Are we actually creating the scaffold or just imagining abstractly what it might one day become?

The questioning stopped. A minimum usable object was defined and built.

6. The first package

The resulting alpha contains 45 files, including 43 populated Markdown documents, a SHA-256 manifest, and a fictional mixed-media pilot called The Kitchen Table Tape Rescue.

7. Public principles

  • universal Scaffold access;
  • commercial and non-commercial use;
  • private adaptations permitted;
  • Archivo 21 attribution required when material is shared;
  • no support, approval or affiliation implied;
  • historical releases remain frozen;
  • projects choose their own versions;
  • human legal accountability remains human.

8. What remains private

Raw exchanges, private annotations, personal context, external individuals, security details and abandoned person-directed material remain in restricted archives. Their omission is documented rather than disguised.

9. What the first alpha must prove

The next meaningful evidence is an independent project using the Scaffold in real work and revealing which parts help, obstruct or can be removed.
