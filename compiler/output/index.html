Accepted interface

  1. Start with a carefully worded first screen.
  2. Use four ordinary button-links on every operational screen.
  3. Keep the first four choices away from the blue screen.
  4. Use POWER conditionally where it is the only blue-screen route.
  5. Use TURBO to remap all four ordinary choices to the blue screen.
  6. Let the blue screen contain only a decoy four-choice board.
  7. Let the turbo blue screen reveal the text-only favicon screen.
  8. Perform no external action whatsoever.
