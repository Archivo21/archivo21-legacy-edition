COMPILER DESK / CONCEPT PRESERVATION COPY

This page preserves the idea behind the first Compiler Desk design without reproducing the withdrawn example that briefly occupied it.

The four-part model

  1. Draft 001: an initial candidate generated for review. See the generic source specification.
  2. lcd97's Draft 002: a human revision that changes wording and intent. See the generic human correction.
  3. Clause decisions: addressable questions and compiler results. Open decisions 001–004 or 005–008.
  4. Draft 003: a clean successor compiled after accepted conditions resolve. See the generic compiled output.

Each stage remains a separate HTML document. The current A21 Compiler demonstration preserves that principle while turning explanation into a comic operating-system sequence.
