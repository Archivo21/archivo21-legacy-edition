Compatibility Log

This edition is designed for the widest practical range of devices that can still connect to the modern encrypted web.

What it requires

  • ordinary HTML links;
  • basic text rendering; and
  • HTTPS and UTF-8 support at the network/browser boundary.

JavaScript, web fonts, cookies, local storage, animation and large images are not required. CSS, tiny tiled GIF backgrounds and the five-refresh Compiler enhancement are optional. Disable any of them and the complete reading order remains available.

Deliberate old-web features

  • HTML 4.01 Transitional output;
  • numeric access keys from 0 to 9;
  • solid body colours with tiny repeating GIF tiles;
  • plain links, headings, lists, quotations, code and tables;
  • no client-side routing or script-dependent reading controls;
  • short global navigation and a complete A-Z index; and
  • a link-driven Compiler Desk that demonstrates addressable review without client-side code.

Honest limit

Many genuine WAP 1.x handsets cannot negotiate current TLS, DNS or cipher requirements. This site therefore uses a WAP-shaped, Web-1.0-compatible HTML approach rather than falsely claiming universal WML handset access.
