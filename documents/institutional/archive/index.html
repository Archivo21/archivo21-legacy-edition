Institutional Archive

This directory preserves exact drafts, superseded texts and migration sources that explain how current records developed.

An archived copy is evidence, not the current authority. The Institutional Document Register identifies the canonical version of every numbered record.

  • Drafts retains unadopted and pre-adoption text.
  • Superseded retains materially different replaced versions and defective compilations.
  • Migration Sources retains exact copies whose former repository location is part of their history.
  • Internal Session Records records controlled sources that are not automatically published.

Do not edit an exact preserved source merely to make it conform to current house style. Add a wrapper or reconciliation note instead.
