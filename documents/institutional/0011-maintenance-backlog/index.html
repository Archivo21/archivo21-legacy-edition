Purpose

This is not a roadmap and not a dumping ground for every ambition.

It is a reservoir of small and medium tasks that can be completed independently when there is not enough time or energy for a full project session.

A task belongs here when it:

  • has a clear stopping point;
  • requires little or recoverable context;
  • can be completed without coordinating several other tasks;
  • leaves a visible record or improvement;
  • is unlikely to expand into a whole day.

Tasks that require major decisions, extensive dependencies, destructive repository changes or sustained experimentation belong in a day plan, roadmap, issue or dedicated work package instead.

Time buckets

The buckets are estimates, not targets. A fifteen-minute task taking twenty minutes is not a failed experiment. It is a clock behaving like a clock.

Maintenance note

When a task is discovered during other work:

  1. complete it immediately only if it does not derail the current objective;
  2. otherwise place it in the most realistic time bucket;
  3. include enough context that another contributor can understand it later;
  4. move it to the roadmap or a dedicated work package if dependencies grow;
  5. preserve completion or retirement rather than making the trail evaporate.
