Decision

Archivo 21 will maintain a dedicated repository, proposed as Archivo21/institutional-records, as the canonical home for uniquely institutional files.

ANHQV-TS2 and the Archivo 21 website retain distinct responsibilities.

Repository responsibilities

Repository Canonical responsibility Must not become
institutional-records Institution-wide constitution, governance, standards, policy, continuity, planning, participation records and documentary history A project evidence repository or website build output
anhqv-ts2-preservation-project ANHQV-TS2 governance, research, evidence, recruitment, contributor archives, releases, finance and sources Archivo 21's constitution, membership register or institution-wide policy store
archivo21.github.io Institutional website source, deployment configuration, presentation assets and rendered public copies A second canonical institutional archive or ANHQV evidence repository

Mixed documents

When one file currently serves institutional and project purposes:

  1. preserve the original pre-migration version;
  2. create or update the institution-wide canonical record;
  3. retain a project-specific file containing only what the project needs;
  4. cross-link the two records;
  5. do not imply that project participation confers institutional status.

Website hierarchy

The Archivo 21 website represents the institution first.

Its primary public structure should lead with institutional identity, constitution, governance, standards, policies and documentary record. ANHQV-TS2 is presented as Archivo 21's current flagship project within a distinct Projects area.

Until ANHQV-TS2 has its own equally polished website, the institutional site may publish readable project-document pages for transparency. Those pages remain clearly project-scoped and subordinate to the institutional information architecture.

Canonical-source rule

The website links readers to rendered webpages. Each document page may then link to its canonical repository source.

Direct internal links to raw .md, LICENSE, notice or other plain-text files are not public navigation destinations.

Migration disposition

  • Move #0008 Change Documentation Policy from website authority to institutional authority; leave an operational pointer in the website repository.
  • Split the mixed ANHQV-TS2 Attribution and Institutional Relationship files.
  • Keep ANHQV contributor archives in the project while adding scope notes and, only where confirmed, specific institutional identity cross-references. The identifier sequences remain independent.
  • Keep project-specific evidence, terminology, finance and recruitment records in ANHQV-TS2.
  • Preserve exact source drafts and superseded versions in the institutional archive.

Review trigger

Review this boundary if a second Archivo 21 project begins, ANHQV-TS2 receives a standalone website, a legal entity is formed, or repository responsibilities repeatedly overlap.
