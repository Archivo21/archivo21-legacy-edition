ANHQV-TS2 Working Evidence Categories

Related institutional draft: #0004 Archivo 21 Evidence Standard

Scope

These categories describe the source types currently used inside ANHQV-TS2. They are project guidance, not an institution-wide Archivo 21 standard.

Institutional #0004 remains a separately governed draft confidence ladder. If that draft is adopted, this project guide should be reconciled deliberately rather than silently treated as equivalent.

Primary evidence

  • Gameplay recordings
  • Raw screenshots
  • Game files
  • Package analysis
  • Series footage
  • Dialogue

Secondary evidence

  • Community tutorials
  • Forum discussions
  • Developer interviews
  • Existing documentation

Tertiary evidence

  • Reasoned hypotheses
  • Observed patterns
  • Speculation

These should always be clearly identified as such.

No hypothesis should be presented as an observed fact.

Relationship to confidence

Source category and confidence are different questions. A primary source may still be ambiguous, incomplete or misinterpreted; a secondary source may direct researchers to a reproducible result.

The project should record both the source relied upon and the confidence claimed.
