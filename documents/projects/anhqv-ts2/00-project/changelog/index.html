Changelog

This document records changes that affect how the ANHQV × The Sims 2 Preservation Project should be understood, used, or preserved.

Git history records ordinary development. This changelog records public milestones, methodological changes, important corrections, structural migrations, and releases.

Unreleased

Changed

  • The three short built-in-recorder tests formerly grouped with EXP001 were reclassified as EXP000 because they test recording quality rather than the two-click-foundation hypothesis.
  • Direct platform URLs for the three EXP000 review copies were removed from the public project documentation. The approved original Short remains embedded as public evidence on Archivo 21's EXP000 page; the other review copies may be shared directly with prospective editors.

Fixed

  • Updated the roadmap, release record, changelog, and citation metadata after publication of the formal v0.1.0 — Research Preview GitHub Release on 2026-07-26.

Planned

  • Inventory all raw experiment videos held in lcd97's complete local working copy.
  • Interview a Video Editor Specialist.
  • Produce a public EXP001 demonstration without replacing the raw evidence.
  • Complete the EXP001 field report and conclusions.

v0.1.0 — 2026-07-26

Added

  • Public GitHub repository established at Archivo21/anhqv-ts2-preservation-project.
  • Public README, contribution guide, recruitment page, Code of Conduct, licence, rights notice, citation metadata, Git attributes, and Git ignore rules.
  • Structured GitHub issue forms and pull-request template.
  • Source governance structure and ANHQV.eu source record.
  • Decision and review-history area.
  • Video evidence policy and inventory.
  • Canonical project naming: ANHQV-TS2, with the nickname Aquí Sims Hay Quien Viva.
  • Financial-governance policies, committee charter, conflict policy, transparency rules, and working templates.
  • Detailed human–AI collaboration and attribution record.
  • Institutional Relationship.md, distinguishing Archivo 21 from ANHQV-TS2.
  • Public report for SIM-INT-001 — Cleverbot.
  • Major-section landing pages so the intended repository structure remains visible in Git.
  • Public links for three clean EXP001 viewing copies.

Changed

  • ANHQV was made explicit as the cultural subject and emotional centre; The Sims 2 is the medium and experimental laboratory.
  • Recruitment Pack review amendments R-001, R-002, and R-003 were integrated into the active documents.
  • Contributor identity, mission role, permission level, and institutional status remain separate.
  • ANHQV-TS2 recruitment was distinguished from Archivo 21 institutional participation.
  • Archivo 21 was documented as not currently recruiting as an institution.
  • The current founding project contributors are identified as lcd97 (ANHQV-HUM-001) and Archivo 21 (ANHQV-AI-001).
  • Two live interviewers remain preferred; a Reviewing Moderator may instead perform an independent documentary review when only one interviewer attends live.
  • Video Editor Specialist was documented as the first public ANHQV-TS2 recruitment priority.
  • The first formal ANHQV-TS2 recruitment process was opened.
  • SIM-INT-001 — Cleverbot was completed and classified as Process validated with revisions, with the session separately recorded as ending early.
  • The Cleverbot interview protocol was revised to version 1.1 with updated capture methods, responsiveness categories, repair limits, stop conditions, and post-termination rules.
  • The Cleverbot report template was revised to version 1.1 with transcript-completeness, capture-method, evidence-classification, early-termination, inference-check, and publication-excerpt fields.
  • The public Cleverbot report was limited to selected procedurally relevant excerpts, while the complete transcript remained in the private archival record.
  • The roadmap, Project Brain, README, release record, recruitment documentation, and citation metadata were aligned with the repository's public state.
  • The contributor-interest form was clarified as applying only to ANHQV-TS2 project roles.

Fixed

  • Restored .gitattributes, .gitignore, GitHub issue forms, and the pull-request template omitted by the initial browser upload.
  • Removed the accidentally duplicated anhqv-ts2-preservation-project/ tree from the repository root.
  • Corrected pre-publication wording in the README, Project Brain, roadmap, release record, and citation metadata.
  • Removed the accidental path-style heading from Collaboration Principles.md.
  • Added the missing .github/ contribution-control structure through GitHub's browser editor.
  • Corrected the public Cleverbot report's filename and location so it renders as Markdown inside the SIM-INT-001 - Cleverbot record.

Archived

  • AI-specific interview and selection documents were moved to historical notes because the current framework recruits by capability rather than implementation.
  • The complete verbatim SIM-INT-001 transcript was retained in the private archival record rather than published in full.

Media

  • Raw MKV and AVI evidence was excluded from the public GitHub repository.
  • Three raw recordings in the transfer snapshot were inventoried by path, size, duration, and SHA-256 checksum.
  • Three clean EXP001 YouTube viewing copies were linked and distinguished from additional local recordings requiring editing.
  • Additional original recordings omitted from the transfer snapshot remain in lcd97's local custody and require inventory.

Changelog Principles

  • Do not rewrite old entries merely because later knowledge changes.
  • Add a correction or superseding entry.
  • Link to the relevant experiment, source record, decision, or release whenever possible.
  • Distinguish changed evidence from a changed interpretation.
  • Never describe unverified work as completed.
