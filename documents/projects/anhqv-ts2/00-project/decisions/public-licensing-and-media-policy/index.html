Public Licensing and Media Policy

Decision date: 2026-07-25
Status: Active for v0.1 Research Preview

Decision

Original project documentation is offered under CC BY-SA 4.0, to the extent that project contributors hold the necessary rights.

Third-party material is excluded and retains its own legal status.

Raw MKV and AVI experiment recordings are not committed to the initial GitHub repository. Three clean built-in-recorder tests are classified as EXP000; direct platform URLs are reserved for controlled review, except for the original Short embedded as public evidence on Archivo 21's EXP000 page.

Licensing Rationale

CC BY-SA 4.0 was selected because it:

  • permits copying, adaptation, translation, and redistribution;
  • requires attribution and preservation of provenance;
  • requires adaptations to remain under the same or a compatible ShareAlike licence;
  • supports reuse by fan archives, wikis, educators, video creators, and preservation projects;
  • avoids a non-commercial restriction that could make useful open-knowledge and preservation reuse legally uncertain or incompatible.

The licence grants only rights held by the licensors. It cannot relicense ANHQV, The Sims 2, or third-party sources.

Media Rationale

Raw recordings are large, may contain irrelevant private audio, and are not equivalent to public demonstrations.

The initial public repository therefore contains:

  • an inventory and checksums;
  • experiment documentation;
  • media policy;
  • a public evidential embed for the approved EXP000 Short and controlled review access for the other platform copies;
  • future edit logs and approved exports.

It does not contain the raw MKV and AVI files.

Review Triggers

Review this decision when:

  • the project begins publishing source code or mods;
  • a formal media archive is selected;
  • Git LFS or release storage becomes necessary;
  • rights holders grant or withdraw permission;
  • the project deposits a version with an archival repository;
  • a different licence is proposed for a distinct class of material.
