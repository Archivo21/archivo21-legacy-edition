Source Records

This directory contains one Markdown record for each formally registered source.

A source record describes:

  • identity and provenance;
  • research value;
  • relevant sections or components;
  • reliability and limitations;
  • verification requirements;
  • rights and preservation status;
  • proposed project use;
  • review history.

Records are organised primarily by the form in which the source is encountered, not by whether it concerns ANHQV or The Sims 2.

Current categories:

  • audiovisual/
  • people/
  • physical-media/
  • print/
  • software/
  • web/

A source that spans categories should be filed according to its principal form and cross-referenced where useful.

Do not create a source record merely to fill a directory. Empty categories may remain empty until a real source requires them.

Use ../Templates/source-record-template.md when registering a new source.
