Boundary rule

  • Institution-wide authority belongs in Archivo21/institutional-records.
  • ANHQV-TS2 project authority belongs in its project repository.
  • This repository controls presentation, deployment, contact state, website assets and generated public copies.

If a website document starts establishing institution-wide policy, move that authority to the institutional repository and leave a clear website application pointer.
