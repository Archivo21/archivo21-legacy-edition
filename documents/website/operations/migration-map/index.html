Former website snapshots

The first site copied selected Markdown into reference/. Those files became stale and blurred repository authority.

The publication candidate:

  1. preserves the snapshots in Git history and the pre-change recovery package;
  2. removes them from the current website tree;
  3. generates formatted HTML from the current canonical candidates;
  4. replaces every public snapshot link with a webpage route;
  5. records the canonical repository on each document page.
